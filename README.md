## What I'm building 🛠️

[**Bank Database Admin**](https://github.com/Antonsalib/bank-database-admin) — a full-stack banking administration demo built with Python, Flask, SQLAlchemy, and MySQL. It connects a web dashboard and forms to a normalized nine-table database for customers, joint account ownership, branches, payment cards, transactions, and loans.

I built the workflows from the interface through the database: transfers post paired debit and credit entries in one transaction, MySQL triggers update account balances, and loan repayments link principal and interest to the account ledger. The project also includes synthetic sample data and a migration from the original schema.

[**Tic-Tac-Toe**](https://github.com/Antonsalib/Tic-Tac-Toe) — a team-built web app with a React frontend and a Node.js/Express backend. It uses the OpenAI API for AI opponent moves and Sequelize with an in-memory SQLite database to track player results and power a sortable leaderboard, with customizable themes and sound controls.
